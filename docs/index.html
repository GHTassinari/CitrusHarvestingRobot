Citrus Harvesting Robot

An open, low-cost, 3D-printed tracked robot for selective, single-fruit orange harvesting, built on a layered Internet of Things architecture.

View on GitHub Printed parts Download STL files

About the project

Table oranges are still picked by hand, while mechanical shakers damage the tree and the fruit. This project proposes a small mobile robot that harvests one fruit at a time. The hardware is organised in four IoT layers: perception (Kinect v2 depth camera, motors and servos), network (USB and Wi-Fi), processing (Raspberry Pi 4 at the edge and Arduino Mega 2560 for real-time control) and application (remote supervision, future work).

The robot was developed with the Design Science Research method for an undergraduate thesis in Information Systems at IFSULDEMINAS – Campus Machado, Brazil (2026). All mechanical files are released as open hardware under CC BY-SA 4.0.

Key specifications

ItemSpecification
ChassisTwo 248 × 200 mm PETG plates, TPU tracks, skid steering, 2 × JGY370 12 V 130 RPM worm-gear motors
ElevatorPrinted Ø16 mm lead screw (8 mm lead) on a steel M8 core, JGY370 40 RPM motor
SensingMicrosoft Kinect v2 (RGB + time-of-flight depth)
ComputingRaspberry Pi 4 (8 GB, Ubuntu Server 24.04) + Arduino Mega 2560 over USB
PowerLiPo 3S 5000 mAh, isolated 5.0 V logic and 5–6 V servo rails, 3 × BTS7960 H-bridges
FabricationFreeCAD, Bambu Lab A1, PETG and TPU, M3/M5 screws and nuts only
